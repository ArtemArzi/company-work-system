# Операции компании

Выбрать нужную процедуру по запросу. Один метод в standards, один recipe рядом с каждым SKILL; общего движка нет.

- [Найти компанию и актуальную работу](company-context/SKILL.md) — Для входа нового сотрудника/сеанса и поиска текущего владельца; читать File Memory независимо от recall.
- [Принять сообщение в работу](company-intake/SKILL.md) — Для разрешённого сообщения или транскрипта: сохранить исходный смысл, неизвестное и подтверждение поручения.
- [Выполнить и проверить задачу](company-execute/SKILL.md) — Для принятой задачи с заранее заданным выходом: выполнить разрешённое действие и проверить exact artifact.
- [Сводка действий и ожиданий](company-summary/SKILL.md) — Для вопроса руководителя о действиях/ответственных/блокерах и готовой передачи следующему получателю.
- [Разобрать рабочие эпизоды](company-episodes/SKILL.md) — Для анализа пути, повторяемых сценариев и слепых зон по разрешённым источникам с явным знаменателем.
- [Ограниченный поиск и сбор](company-research/SKILL.md) — Для конкретного неизвестного вопроса: первичные источники, противоречия, готовые компоненты, границы чтения.
- [Подготовить маркетинговую операцию](company-marketing/SKILL.md) — Для предложения, материала или эксперимента с аудиторией/нужным действием и источником показателя.
- [Получить данные узким инструментом](company-source-read/SKILL.md) — Для чтения принятой выгрузки/API/MCP: проверить account/company/scope/период/полноту и сохранить основания.
- [Сохранить и доставить общую версию](company-deliver/SKILL.md) — Для разрешённого внутреннего результата, кандидата обновления или обезличенного предложения через единый Git-путь.
- [Создать или улучшить навык](company-author/SKILL.md) — Для обоснованной повторяемой операции: reuse, стандарт, SKILL/YAML, правильный и плохой пример, версия.
- [Разобрать сбой и исправить причину](company-incident/SKILL.md) — Для воспроизводимой ошибки: первое неверное допущение, challenge research, малое исправление и повтор исходного теста.
- [Найти знание и связи с основаниями](company-knowledge/SKILL.md) — Для поиска по алиасам/первичному материалу или принятой внешней KB; граф остаётся производным.
