# Создание навыка

Проверить повторяемую нужду и существующую операцию. Один запрос не обязан стать навыком. Использовать метод skill-creator при доступности; чужую библиотеку автоматически не устанавливать. Один канонический skills/<id>/SKILL.md с name/description, коротким выбором/выходом и ссылкой на стандарт. workflow.yaml рядом владеет шагами/зависимостями/входом/выходом/проверкой/ошибкой/остановкой; frontmatter и UI metadata имеют другое назначение.

Версия рецепта, стандарта и инструмента согласованы. Проверить safe YAML, уникальные шаги/ID, известные возможности, зависимости без циклов, ссылки и ресурсы, место и согласованность навыка. Запустить skill-creator quick_validate и правильный/плохой сценарии. Discovery и исполнение проверяются в каждой заявленной среде отдельно; явное чтение не означает native discovery. SKILL ссылается на метод, не копирует его. Общий цикл task-validation; изменение — через сопровождающего/template-update. Пример, local, live и применение различать.
