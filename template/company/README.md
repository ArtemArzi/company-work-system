# Карта компании

[Как устроена работа — визуальное руководство для команды](../docs/company-system-guide.html).

Текущий контекст, определения, полномочия и включённые функции принадлежат [config.yaml](config.yaml). Настроить по решениям владельца; пустое значение остаётся неизвестным. У компании отдельный закрытый Git и отдельные реальные аккаунты.

| Блок | Искать здесь |
| --- | --- |
| [Руководство](management/README.md) | цели, решения, очередь, ожидание, сводка действий |
| [Операции](operations/README.md) | повторяемый эпизод, передачи, исход, слепая зона |
| [Маркетинг](marketing/README.md) | предложение, материал, эксперимент, показатели |
| [Продажи](sales/README.md) | обращение, подтверждённое поручение, следующий получатель |
| [Проекты](projects/README.md) | проект, зависимости, исполнитель, готовый результат |
| [Люди и обучение](people/README.md) | первое полезное действие, самостоятельное повторение, знания |
| [Финансы](finance/README.md) | сверка источников и единиц без догадок о платежах |
| [Закупки](procurement/README.md) | остаток на складе, единица, период, определение запаса |

[Навыки](../skills/README.md) → [процесс сообщения](../workflows/message-to-action.yaml).

[Источники](sources/README.md). Задачи — work/<id>/task.json, найти через `python3 scripts/system.py context`. Карта не дублирует их статусы.
