# Проекты

Область поиска: проект, зависимости, исполнитель, готовый результат. Владелец и определения — [действующий config](../config.yaml); в чистом комплекте определения и источник неизвестны. Не выводить их из названия блока.

Процедура: [company-execute](../../skills/company-execute/SKILL.md). Критерии — [общий цикл](../../standards/task-validation.md) и выбранное местное определение из config.bindings. Источники — [карта источников](../sources/README.md), их реальная область доступа проверяется до чтения. Состояние разовой работы — ../../work/<id>/task.json; новых копий статуса здесь нет.

После первого разрешённого прохода проверить передачу соседнему получателю и самостоятельный повтор. Время/нагрузку участников, baseline, использование и стоимость сопровождения фиксировать только по наблюдениям у задачи; KPI, стимулы, права, бюджет и приоритеты неизвестны до решения компании.
