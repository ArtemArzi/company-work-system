# Рабочая система компании

Откройте Codex или Claude Code в репозитории компании. Поставьте задачу обычными словами и попросите прочитать [AGENTS.md](AGENTS.md). Например: «Сохрани поручение подготовить сводку заявок; непонятное оставь вопросом» или «Покажи, кто чего ждёт и что делать дальше». Агент находит метод, выполняет разрешённое действие, проверяет, сохраняет и доставляет результат. Файловая память работает независимо от памяти чата.

[Карта компании](company/README.md) → нужный бизнес-блок → [операция](skills/README.md) и её рецепт. У каждой задачи один task.json с историей и продолжением; исходный запрос, источники и результат рядом. Нет подтверждения поручения/источника/права — агент сохраняет ожидание и конкретного владельца решения. Корректные обычные результаты не требуют ручного чтения каждого файла.

Сопровождающему: [точные форматы и команды](standards/runtime.md), [подключения](standards/data-access.md), [копирование/доставка/обновление/восстановление](standards/template-update.md). Настроить только известное в company/config.yaml: company/owner/local_work, источники/период/единицы, принятые местные правила и реальные права. Финансы, KPI, бюджет, квоты и неизвестные бизнес-правила по умолчанию не заданы. Источники с ограниченным доступом остаются у provider; роль в тексте не скрывает файл от пользователя repo.

Поддержанный программный путь: Python3.12+, PyYAML6.0.1, Git2.43+, Linux. [Codex](adapters/codex/profile.yaml) и [Claude](adapters/claude/profile.yaml) имеют общую процедуру explicit-file-read и отдельные статусы native. Windows/cloud, неизвестные коннекторы, hooks и глобальная память автоматически не подключаются. Локальная выгрузка/transport tests отличаются от live аккаунта.

Проактивный tick выключен до принятой настройки; расписание не устанавливается автоматически. Граф производен, при выключении работает прямое чтение файлов; внешняя KB включается отдельно. Внутренние документы разработки продукта отсутствуют в этом комплекте. Локальные программные проверки, native запуск, общая Git-доставка, полевое применение и эффект различаются; не считать их одним успехом.
