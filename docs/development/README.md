# Документы разработки продукта

1. [PLAN.md](PLAN.md) — принятый способ, полный P0–P8, общий прогресс и следующий этап.
2. [Текущая реализация](work/company-template/task.md) — конкретные решения, выполненные проверки, ошибки и следующий шаг агента.
3. [Свидетельства](work/company-template/evidence/) — вывод проверок и сохранённые примеры ошибок.
4. [Выпуск функции и обновление компаний](RELEASE.md) — штатный маршрут из product main через изолированный пакет.

Документы разработки принадлежат продукту. Бизнес-состояние экземпляра компании находится в её work/<id>/task.json. Выпуск включает только template/ и его split-историю; этот каталог исключён.
