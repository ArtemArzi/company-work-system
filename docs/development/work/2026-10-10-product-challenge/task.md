## Способ и основания

Применены deep-research и business-hypothesis-check: первичные источники, независимые направления, сравнение ожиданий с наблюдениями, unknown отдельно от отрицательного результата. Три read-only ветки: текущий код; агентные системы; процессы/внедрение/проверка пользы. Root проверил происхождение идей, ключевые источники и подготовил синтез. Дети не меняли код и не создавали детей.

Штатный product preflight первоначально blocked; безопасная диагностика wrapper fetch показала DNS failure. Обычный `git ls-remote` подтвердил совпадение main с local SHA. Затем штатный preflight с разрешённым сетевым выполнением дал `ready/current/fresh=true`, обе стороны `d116e7b...`. Ошибка среды не объявляется дефектом продукта. Root Work preflight первоначально blocked; исследование не зависит от обновления экземпляра Work.

Firecrawl search вернул HTTP 402: использован web fallback; в одной внешней ветке также Tavily. Кэш веб-страницы GitHub показывал старую 1.2.0, поэтому версия установлена по Git и release.yaml. Маршрутизатор не дал уверенного решения; работа выполнена по явному запросу сабагентов и действующей политике ролей, без контроллера и изменения конфигурации.
